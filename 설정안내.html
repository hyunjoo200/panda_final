학생 결과와 반 순위를 모으는 설정

처음 한 번만 하면 되고 15분쯤 걸려요. 구글이 무료로 주는 저장소(Firebase)를 쓰고, 결제 카드는 등록하지 않아요. 4차시부터는 같은 설정을 그대로 씁니다.

설정을 하지 않아도 게임은 그대로 돼요. 다만 결과와 순위가 학생 각자의 기기에만 남고, 선생님 화면에는 아무도 나타나지 않아요.

1. Firebase 프로젝트 만들기

1프로젝트 만들기

console.firebase.google.com에 구글 계정으로 들어가 프로젝트 만들기를 눌러요. 이름은 chinese-panda처럼 영어로 쓰고, 애널리틱스나 AI 도우미를 묻는 화면은 사용 안함으로 넘어가요.

요금제는 무료(Spark)로 시작해요. 업그레이드하라는 버튼은 누르지 않아요.

2로그인 방법 두 개 켜기

왼쪽 메뉴에서 Authentication을 찾아 들어가 시작하기를 눌러요. (메뉴 묶음 이름이 빌드나 Security로 보일 수 있어요. 안 보이면 위쪽 검색창에 Authentication을 입력해요.) 로그인 방법 탭에서 익명을 사용 설정하고 저장, 이메일/비밀번호도 사용 설정하고 저장해요.

익명 = 학생이 회원가입 없이 들어오는 방법, 이메일/비밀번호 = 선생님 로그인.

3선생님 계정 만들기

같은 화면의 사용자 탭 → 사용자 추가. 선생님 이메일과 비밀번호(6자 이상)를 넣어요. 이 이메일을 6단계에서 다시 써요.

4게임 주소 허락하기

Authentication의 설정 탭 → 승인된 도메인 → 도메인 추가에 내아이디.github.io를 넣어요. (GitHub 주소에서 https://와 뒤의 /저장소이름/을 뺀 부분)

2. 결과 저장소 만들기

5Firestore 데이터베이스 만들기

왼쪽 메뉴에서 Firestore를 찾아 들어가 데이터베이스 만들기를 눌러요. (요즘 화면에서는 Databases & Storage 묶음 안에 있어요. 안 보이면 검색창에 Firestore를 입력해요.) 에디션을 물으면 Standard, 위치는 asia-northeast3 (Seoul), 시작 모드는 프로덕션 모드를 골라요.

위치는 나중에 바꿀 수 없어요. 서울을 꼭 골라 주세요.

6보안 규칙 붙여 넣기

Firestore의 규칙 탭에서 원래 글을 모두 지우고, 함께 드린 firestore-rules.txt 내용을 붙여 넣어요. 그 안의 teacher@example.com을 3단계 이메일로 바꾸고 게시를 눌러요.

이 규칙 덕분에 학생은 자기 기록과 순위(이름·점수)만 볼 수 있고, 문제별 자세한 결과와 삭제는 선생님만 할 수 있어요.

3. 게임과 연결하기

7웹 앱 등록하고 값 복사하기

왼쪽 위 톱니바퀴 → 프로젝트 설정 → 아래쪽 내 앱에서 웹 아이콘 </>을 눌러 앱 이름을 쓰고 등록해요. (Hosting 설정은 체크하지 않아요)

화면에 나오는 firebaseConfig의 여섯 값(apiKey, authDomain, projectId, storageBucket, messagingSenderId, appId)을 firebase-config.js의 같은 이름 따옴표 안에 하나씩 붙여 넣어요.

8GitHub에 다시 올리기

고친 firebase-config.js를 GitHub 저장소에 올려요(Add file → Upload files → Commit changes). 1~2분 뒤 반영돼요.

4. 잘 되는지 확인하기

9학생 화면

게임 주소를 열고 이름을 써서 시작해요. 오른쪽 위 🏆 옆 작은 점이 초록색이면 연결된 거예요. 노란색은 연결 중, 빨간색은 오류(4단계 도메인이나 7단계 값을 다시 확인).

10선생님 화면

게임 주소 끝에 teacher.html을 붙여 열어요. 예: https://내아이디.github.io/panda-lesson3/teacher.html. 3단계 이메일로 로그인하면 방금 들어온 학생이 보여요.

4차시부터는

Firebase 설정은 그대로 써요. 새 차시 저장소에도 같은 값을 넣은 firebase-config.js를 올리기만 하면 돼요. 저장소 주소가 같은 내아이디.github.io라면 4단계도 다시 할 필요가 없어요. 선생님 화면은 차시마다 그 저장소의 teacher.html을 열거나, 아무 차시의 선생님 화면에서 차시 칸에 lesson3, lesson4처럼 입력해 불러와요.

수업할 때

하고 싶은 일방법
학생에게 링크 주기게임 주소를 그대로 줘요. 카카오톡으로 받은 학생은 다른 브라우저로 열기를 하도록 안내해요(소리 문제 예방).
반을 나누어 보기주소 끝에 ?class=3반을 붙여 반마다 다른 링크를 줘요. 선생님 화면의 반 칸에 같은 글자를 쓰면 그 반만 보여요. 순위표도 반끼리만 나와요.
순위 함께 보기선생님 화면의 🏆 순위 크게 보기를 화면 공유해요.
결과 보관CSV 저장으로 내 컴퓨터에 내려받아요(엑셀에서 열려요).
수업 뒤 지우기이 날 결과 삭제 → 삭제라고 입력. 남은 기록 수가 0인지 확인해요.

무료 한도와 개인정보

무료 한도는 하루 쓰기 2만 번, 읽기 5만 번이에요. 15명이 한 판 하면 쓰기 약 1,500~2,000번이라 하루 여러 반도 충분해요. 한도를 넘어도 요금이 나가지 않고 그날 저장만 멈춰요.
저장되는 것은 학생이 쓴 이름·별명과 게임 기록뿐이에요. 실명 대신 별명을 쓰게 하고, 학교의 외부 서비스 사용 기준을 먼저 확인해 주세요. 저장 위치는 구글 서울 데이터센터예요.
