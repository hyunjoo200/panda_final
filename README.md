# 중국어 탐험대 · 마지막 차시 — 판다의 졸업 대모험 🎓

마리오처럼 달리고 점프하는 2스테이지 졸업 게임이에요. **차시마다 가장 중요한 표현을 종 하나씩** 모았어요. (문제 16개: 종 10개 + 괴물 O/X 6개, 약 10~12분)

- ☀️ **1스테이지 (밝은 낮)**: 1~6차시 종 6개 → **꼬마 대나무 괴물** O/X 3문제 → 이기면 **작은 문**이 열려요.
- 🚪 작은 문에 들어가면 화면이 어두워졌다가 **STAGE 2 · 어둠의 숲**으로!
- 🌙 **2스테이지 (어두운 밤)**: 8~11차시 종 4개 → 언덕 위 **거대한 어둠 괴물** O/X 3문제
- 🎉 괴물을 이기면 화면이 깜깜해졌다가 환하게 밝아지며 빵빠레와 함께 **我会说一点儿汉语！**가 떠요 → 졸업장(끝 화면).

| 차시 | 핵심 표현 (종) |
| --- | --- |
| 1 | 성조 (妈·麻·马·骂 성조 번호) |
| 2 | 对不起 → 没关系 |
| 3 | 你叫什么名字？ (순서 맞추기) |
| 4 | 我是中国人。 (듣고 국기) |
| 5 | 三十六 |
| 6 | 十一月九号 |
| 8 | 这是我妈妈。 |
| 9 | 我想吃炸酱面。 (듣고 음식 사진) |
| 10 | 你喜欢什么？ → 我喜欢猫。你呢？ |
| 11 | 最近怎么样？ → 我很好。你呢？ |
| 꼬마 괴물 | O/X: 이름 묻고 답하기, 생일, 谢谢/不客气 |
| 거대 괴물 | O/X: 你喜欢什么, 你想吃什么, 好久不见！最近怎么样？ |

쉬워진 점: 버섯과 부딪혀도 별이 줄지 않고, 구덩이에 빠지면 지나온 종 근처에서 다시 시작해요.

## 올리기
새 저장소(예: panda-final)에 zip 안의 파일을 모두(**img 폴더 포함**) 올리고, `firebase-config.js`는 이전 차시 것을 복사해요. 선생님 화면 차시 칸: `lesson12`.
(firestore-rules.txt는 10차시 때 붙여 넣은 규칙과 같아요. 다시 붙여 넣을 필요 없어요.)

## 고치기 (game-data.js)
- 문제: `zones` → `missions` (줄이려면 { id: ... } 묶음을 통째로 지우기, 구역마다 1개는 남기기)
- 괴물 대사·O/X 문제: `bosses`
- 마지막 문장: `finale`
